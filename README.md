# MasterPhrase — Frontend

MasterPhrase is a full-stack language-learning platform with interactive vocabulary and phrase exercises, pronunciation practice, multilingual UI, user accounts, and error-review functionality.

This repository contains the **frontend** application.

## Tech stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- i18next

## Selected functionality

- User registration and login
- Multilingual interface
- Vocabulary and phrase exercises
- Pronunciation recording and playback
- Text-to-speech
- Error review and retraining
- Language preferences
- Training for irregular nouns and strong verbs
- REST API integration

## Local development

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_URL` in your local `.env` before starting the application.
